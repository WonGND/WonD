## 3. 랜딩페이지 호스팅 (5분, 무료)

파일: `site/landing.html`

1. `landing.html` 하단 `<script>`의 `LINKS`에 링크 입력
   (pay = 토스 송금 링크 / form = 구글폼 / sample = 미리보기 PDF 구글드라이브 공유 링크 / contact = 오픈채팅 / kmong_ebook = 크몽 심사 통과 후)
2. https://app.netlify.com/drop 접속 → 파일을 드래그 앤 드롭 → 즉시 URL 발급 (가입하면 URL 유지됨)
   - 대안: GitHub Pages, Vercel. 어디든 정적 HTML 1장이면 됨.
3. 발급된 URL을 모든 홍보 문구의 [링크] 자리에 사용.

## 4. 결제 수단 우선순위

| 순위 | 수단 | 장점 | 단점 |

| 1 | 크몽 | 신뢰·분쟁 보호, 검색 유입 | 수수료 약 20%, 심사 필요 |
