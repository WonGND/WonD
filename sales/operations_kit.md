**설명**:

**질문**:
1. 이메일 주소 (단답형, 필수) — PDF 받으실 주소

4. 어디서 알고 오셨나요? (객관식, 선택) — 지인 소개 / 오픈채팅 / 카페 / 스레드·X / 기타
   ← 4번은 채널별 전환 측정용. 72시간 결산 때 어느 채널에 집중할지 이걸로 결정.

**설정**: 응답 알림 켜기 (응답 → 새 응답 이메일 알림) — 발송 속도가 신뢰다.

## 3. 랜딩페이지 호스팅 (5분, 무료)

파일: `site/landing.html`

1. `landing.html` 하단 `<script>`의 `LINKS`에 링크 입력
   (pay = 토스 송금 링크 / form = 구글폼 / sample = 미리보기 PDF 구글드라이브 공유 링크 / contact = 오픈채팅 / kmong_ebook = 크몽 심사 통과 후)
2. https://app.netlify.com/drop 접속 → 파일을 드래그 앤 드롭 → 즉시 URL 발급 (가입하면 URL 유지됨)
   - 대안: GitHub Pages, Vercel. 어디든 정적 HTML 1장이면 됨.
3. 발급된 URL을 모든 홍보 문구의 [링크] 자리에 사용.

## 4. 결제 수단 우선순위

| 순위 | 수단 | 장점 | 단점 |
|------|------|------|------|
| 1 | 크몽 | 신뢰·분쟁 보호, 검색 유입 | 수수료 약 20%, 심사 필요 |
| 2 | 토스아이디 송금 링크 (toss.me/아이디/금액) | 즉시 개설, 수수료 0 | 구매자 신뢰 낮음 → 지인·소개 경로용 |
| 3 | 계좌이체 + 구글폼 | 즉시, 수수료 0 | 수동 확인 필요 |

- 토스 링크 만들기: 토스 앱 → 전체 → '내 토스아이디' → 아이디 생성 → 금액 지정 링크 공유.
- 크몽 심사 통과 전: 2·3번으로 판매 시작. 통과 후: 랜딩 `LINKS`를 크몽 URL로 교체.
