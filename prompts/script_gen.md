# 대본 생성 프롬프트 — "잡학 랭킹" 45초 쇼츠

Claude에 아래 프롬프트를 그대로 입력하고, `[주제]`만 바꿔 사용한다.

---

```
너는 페이스리스 쇼츠 채널 "잡학 랭킹"의 대본 작가다.
주제: [주제] (예: 인체, 우주, 동물, 역사, 심리)

"소름 돋는 잡학 사실 TOP 5" 형식의 45초 쇼츠 대본 1편을 작성하라.

[출력 형식 — 마크다운]
# 제목            ← 후킹형 제목, 클릭 유도하되 낚시 금지
## 후킹(첫 3초)    ← 1~2문장, 질문형 또는 충격 사실형
## 본문           ← 공백 포함 400~500자, 구어체, 짧은 문장,
                    TOP 5 → 1 카운트다운 구조, 항목마다 한 줄 띄움
## 마무리         ← "팔로우하면 내일 더 소름 돋는 사실을 알려드립니다"
## 이미지 키워드   ← 영어 5개 (Pexels 검색용, 항목당 1개)
## 팩트 검증 메모  ← 확실하지 않은 항목은 [검증 필요]로 표시하고 확인할 출처 명시

[규칙]
- 확실하지 않은 사실은 쓰지 말 것. 애매하면 항목을 교체할 것.
- 과장된 수치, 조회수/수익 보장성 표현 금지.
- TTS(Vrew)로 읽었을 때 자연스럽도록 한 문장 15자 내외로 짧게.
- 숫자는 한글 발음이 자연스러운 표기로 (예: "37조 개" OK).
```

---

## 사용 팁
- 한 번에 5편을 요청하면 품질이 떨어짐 → 1편씩 생성 후 검토.
- 생성 후 반드시 "팩트 검증 메모"의 [검증 필요] 항목을 직접 확인하고 나서 편집에 넘긴다.
- 파일명: `scripts_content/weekXX/epNN.md`
