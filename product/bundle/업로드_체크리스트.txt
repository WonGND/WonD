# 업로드 전 점검 체크리스트 (7항목)

업로드 버튼 누르기 전에 아래 7개를 순서대로 확인한다. 하나라도 미통과면 업로드 보류.

- [ ] 1. **미리보기 확인** — 처음부터 끝까지 1회 재생 (음성 싱크, 이미지 전환 확인)
- [ ] 2. **워터마크 위치** — 채널 워터마크가 자막/UI와 겹치지 않는지 확인
- [ ] 3. **자막 오탈자** — 자막 전체 훑어보기 (특히 숫자·고유명사)
- [ ] 4. **제목 = 후킹 문구** — 대본의 후킹 문구를 제목으로 사용했는지 확인
- [ ] 5. **#shorts 태그** — YouTube 제목 또는 설명에 #shorts 포함
- [ ] 6. **릴스 원본 오디오 유지** — Instagram 업로드 시 오디오가 원본 그대로인지 확인
- [ ] 7. **업로드 시간 18~21시** — 예약 업로드 활용 가능

---
사용법: 이 파일을 복사해서 주차 폴더에 두고 편마다 체크하거나, 업로드 직전에 열어놓고 확인.
