# 판매 전략 v2 — 퍼널 설계

> v1(단일 상품 직접 판매)의 약점 5개를 보완한 개정판.
> 원칙 유지: 수익 보장 표현 금지, 거짓 마감 금지, 부풀림 금지.

## 1. 퍼널 구조 — "뿌리고 끝"에서 "모으고 키우기"로

```
[인지]  스레드·카페·오픈채팅·지인 (7일 콘텐츠 캘린더)
   ↓
[리드]  무료 미리보기 = 이메일 받고 발송 (구글폼 리드 수집)   ← 신규
   ↓
[전환]  상세페이지 — 2단 가격 + 실제 제작 사례 증거          ← 신규
   ↓
[후기]  후기 작성 → 보너스 「소재 100선」 증정               ← 신규
   ↓
[추천]  후기·사례가 다음 인지 콘텐츠가 됨 (순환)
```

핵심 변화: **미리보기를 공짜로 뿌리지 않고 이메일과 교환한다.**
안 산 사람에게 3일 뒤 1회 후속 메일(런칭가 마감 안내)을 보낼 수 있게 된다.
이 후속 1회가 콜드 판매에서 전환의 상당 부분을 만든다.

## 2. 가격 구조 — 2단 (앵커링 + 객단가)

| 구성 | 정가 | 런칭가 | 내용물 |
|------|------|--------|--------|
| 전자책 (PDF 27p) | 19,900원 | **12,900원** | 책 단권 |
| 전자책 + 실행팩 | 29,900원 | **19,900원** | 책 + 바로 쓰는 파일 번들 |

**실행팩** (한계비용 0, 체감가치 큼): 프롬프트 2종 .txt(복붙용) /
소재 50선 .csv(진행 체크용) / 지표 기록 + 30일 캘린더 .xlsx /
업로드 체크리스트 .txt — "책 안 읽고도 오늘 시작되는 파일들"

앵커 효과: 12,900이 "싼 선택지"로 보이고, 실행팩(+7,000원)이 자연 업셀이 된다.
경험상 이런 구조에서 상당수가 상위 옵션을 고른다 — 보장은 아니지만 시도 비용이 0이다.

## 3. 증거 전략 — "실제로 되는 시스템"의 증명

- **제작 사례 섹션(상세페이지)**: 이 책의 마스터 프롬프트로 실제 제작한 영상의
  장면 + 대본 발췌를 상세페이지에 게시. "이 공정으로 실제로 만든 결과물"은
  후기 0개 시점에서 쓸 수 있는 유일한 증거다.
- **베타 리더 10명**: Day 1에 지인·커뮤니티에서 10명에게 무료 증정하고
  솔직 후기를 요청 (조건 명시: "좋게 써달라"가 아니라 "솔직하게").
  후기 3개 이상 모이면 상세페이지에 후기 섹션 추가.
- **후기 리워드(상시)**: 구매자가 후기를 보내면 보너스 「니치별 소재 100선」 PDF 증정.
  후기가 모이는 구조를 상품 안에 내장한다.

## 4. 채널 우선순위 (72시간 기준)

| 순위 | 채널 | 이유 | 기대 |
|------|------|------|------|
| 1 | 지인 전달 요청 + 베타 10명 | 전환율 최고, 후기 씨앗 | 첫 판매 + 후기 |
| 2 | 스레드/X 7일 연작 | 오가닉 도달, 누적 자산 | 리드 유입 |
| 3 | 네이버 카페 홍보판 | 타깃 밀집 | 리드 유입 |
| 4 | 오픈채팅 (신뢰 쌓은 뒤) | 도달 소규모, 즉효 | 소량 전환 |
| 5 | 크몽 (심사 후) | 검색 유입, 신뢰 | 중장기 주력 |

크몽 심사 통과 전까지는 리드 수집(구글폼)이 주 무기.
통과 후에는 크몽을 메인 결제로, 자체 퍼널은 리드·후속용으로 병행.

## 5. KPI — 주 단위로 이것만 본다

- 리드 수(미리보기 신청) / 구매 수 / 리드→구매 전환율
- 채널별 유입(주문서 문항) — 다음 주 집중 채널 결정
- 후기 수 — 3개 되면 상세페이지 반영
- 실행팩 선택 비율 — 30% 넘으면 실행팩을 기본 노출로

## 6. 하지 않는 것

- 유료 광고 (상품 검증 전 금지 — 검증은 오가닉 20부부터)
- 가격 인하 경쟁 (후기가 모이면 가격은 올린다: 12,900 → 19,900)
- 여러 상품 동시 런칭 (실행팩은 '구성 차이'지 신상품이 아니다)
