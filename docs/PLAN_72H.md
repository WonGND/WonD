# 72시간 실행 플랜 — 전자책 단일 상품

## 0. 정직한 전제 (먼저 읽을 것)

- 고단가 세팅 서비스는 운영자 부담이 커서 제외했다. 남은 상품은 **전자책 12,900원 하나**다.
- 12,900원 × 78부 = 100만원. **팔로워 0에서 72시간 안에 78부는 비현실적이다.** 이 플랜의 목표는 "72시간 내 100만원"이 아니라 ① 첫 판매를 만들고 ② 어느 채널이 반응하는지 데이터를 얻고 ③ 이후에도 계속 팔리는 판매 파이프라인을 완성하는 것이다.
- 전자책은 재고·납품 부담이 없는 자산이다. 72시간은 '시작'이지 '마감'이 아니다.

## 4. 판매 시 지켜야 할 것

1. **수익 보장 표현 금지.** 준비된 문구에는 이미 없음 — 임의로 추가하지 말 것.
2. **전자책 내용을 실제보다 부풀리지 말 것.** 27페이지 실행 가이드다. 그대로 팔아도 가격값을 한다.
3. **환불 요청은 빠르게 수용.** 분쟁 1건이 후기 10개를 망친다.
4. **미리보기를 아끼지 말 것.** 1장 전체 공개가 최고의 영업사원이다.

## 4.5 병렬 트랙 — 크몽 외주 서비스 (로컬 PC 세션과 연계)

로컬 PC의 Claude 세션이 같은 미션으로 **크몽 자동화 외주 트랙**을 준비해 뒀다
(`Desktop/Wonyong company/launch-72h/` — 서비스 3종 등록 원고, 견적 응대, 홍보 문구).
두 트랙은 경쟁이 아니라 상호 보완이다:

| | 트랙 A: 전자책 (이 저장소) | 트랙 B: 크몽 외주 (launch-72h/) |
|---|---|---|
| 단가 | 12,900~19,900원 | 33,000~440,000원 |
| 첫 매출 속도 | 지인·베타로 즉시 가능 | 등록 후 3~10일 |
| 운영 부담 | 0 (자산형) | 건당 1~3시간 (Claude가 개발 담당) |
| 100만원 경로 | 60~78부 (장기 누적) | 2~4건 (단기 집중) |

**시너지 포인트**
1. 크몽 전문가 계정 **하나로 둘 다 등록** — 외주 서비스 3종 + 전자책. 등록 김에 같이.
2. 외주 문의자에게 전자책을, 전자책 독자에게 외주 서비스를 교차 안내 (프로필에 상호 링크).
3. 신뢰 자산 공유 — 아래 링크를 전자책 상세페이지·크몽 프로필 양쪽에 사용:
   - 포트폴리오: https://claude.ai/code/artifact/cd3259c7-d764-47ee-8934-657ef525639d (공유 전환 필요)
   - 라이브 데모: https://wongnd.github.io/learning-platform/
   - 공개 코드: https://github.com/WonGND (시크릿 유출 점검 완료)
   - "쇼츠 자동화 파이프라인을 실제로 구축·운영하는 개발자가 쓴 책"이라는 저자 신뢰가 판매 전환의 핵심 증거가 된다.

## 5. 72시간 후 — 계속 팔리게 만들기

- 가격을 정가 19,900원으로 인상 (약속 이행 + 마진 개선).
- **최고의 마케팅은 내 쇼츠 채널 자체**: 원래 프로젝트(잡학 랭킹 채널)를 이 책의 시스템 그대로 운영하고, 채널 설명·고정 댓글에 전자책 링크. "이 시스템으로 실제 운영 중인 채널"이 되는 순간 전환율이 달라진다.
- 구매자 후기가 3개 모이면 상세페이지에 후기 섹션 추가 (Claude에게: "후기 3개로 상세페이지에 후기 섹션 추가해줘").
- 판매가 안정되면 확장: 개정판(v1.1 무료 업데이트 약속 이행), 니치별 소재팩, 대본 구독 등 — 부담 없는 것만.
