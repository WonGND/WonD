# 72시간 100만원 실행 플랜

## 0. 정직한 전제 (먼저 읽을 것)

- **100만원을 72시간 안에 버는 것은 보장할 수 없다.** 팔로워 0에서 시작하는 저단가 상품(전자책)만으로는 확률이 매우 낮다.
- 그래서 이 플랜의 주력은 **고단가 서비스 2건(49만원 × 2 = 98만원)** 이다. 전자책은 보조 수단이자, 72시간이 지나도 계속 팔리는 자산이다.
- 72시간 안에 목표를 못 채워도 **상품 2개(전자책 + 서비스), 판매 페이지, 홍보 문구, 아웃리치 채널이 전부 남는다.** 이건 실패가 아니라 1주차다.

## 1. 목표 산수

| 시나리오 | 구성 | 합계 |
|----------|------|------|
| A (주력) | 서비스 49만원 × 2건 | 98만원 |
| B (혼합) | 서비스 1건 49만 + 전자책 12,900원 × 40부 | 100.6만원 |
| C (전자책 단독) | 12,900원 × 78부 | ⚠️ 신규 계정으로는 비현실적 |

→ **모든 에너지의 70%를 서비스 판매에, 30%를 전자책에 쓴다.**

- 크몽 등 플랫폼 경유 시 수수료(대략 15~20%, 등록 시점 요율 확인)만큼 추가 판매가 필요하다.
- 직거래(계좌이체·토스 송금 링크)는 수수료가 없지만 구매자 신뢰가 낮다 → 지인·소개 경로에서만 사용.
- 소득 발생 시 세금 신고 대상이다. 반복 판매로 키울 거면 사업자등록·통신판매업 신고를 알아볼 것.

## 3. 시간대별 실행 플랜

### Day 1 (0~24h) — 판매 인프라 + 첫 노출

**오전 (2h) — 결제·등록 (심사 지연이 최대 리스크라 무조건 먼저)**
- [ ] 크몽 판매자 등록 + 서비스 상품 등록 신청 (`service_listing.md` 복붙) — 심사에 1~3일 걸릴 수 있으므로 0시간째에 신청
- [ ] 크몽 전자책 상품도 동시 등록 신청 (`ebook_listing.md`)
- [ ] 심사 대기와 무관하게 즉시 파는 경로 확보: 토스 익명 송금 링크 또는 계좌 + 구글폼(주문서) — 전자책은 입금 확인 후 PDF 메일 발송
- [ ] 링크 정리용 원페이지(리틀리 등): 전자책 구매 / 서비스 상담 / 문의 오픈채팅

**오후 (3h) — 네트워크 가동 (전환율이 가장 높은 채널)**
- [ ] 지인 20명에게 "소개 부탁" 메시지 발송 (`outreach_templates.md` 1번) — 판매가 아니라 소개 요청
- [ ] 소개비 5만원 제안 포함 (2건 성사돼도 소개비 10만원, 남는 장사)
- [ ] 스레드/X 계정 정비 + 연작 포스트 1일차 발행

**저녁 (1h)**
- [ ] 부업/유튜브 오픈채팅 3~5곳 가입 (홍보 허용 방 확인) — 첫날은 홍보 없이 대화만 (신뢰 계정 만들기)

### Day 2 (24~48h) — 노출 확장

- [ ] 네이버 카페 2~3곳 홍보 게시판에 게시 (3번 문구) — 규칙 위반 도배 금지
- [ ] 오픈채팅 홍보 허용 방에 게시 (2번 문구)
- [ ] 당근 동네생활/재능 등록 (6번 문구)
- [ ] 스레드 연작 2일차 + 전날 반응 온 사람 전원에게 DM 후속 (5번 스크립트)
- [ ] 상담 문의는 **1시간 내 응답** — 72시간 게임에서 응답 속도가 전환율이다
- [ ] 크몽 심사 통과 시 모든 링크를 크몽으로 교체 (분쟁 보호 + 신뢰)

### Day 3 (48~72h) — 클로징

- [ ] 미결 상담 전원 후속 연락: "런칭가 49만원은 오늘까지, 이후 59만원" (실제로 올릴 것 — 거짓 마감은 금지)
- [ ] 전자책 구매자에게 서비스 업셀 메시지 (구매가만큼 할인)
- [ ] 스레드 연작 3일차(CTA) 발행
- [ ] 72시간 결산: 매출 / 문의 수 / 채널별 반응을 PROGRESS.md에 기록

## 4. 판매 시 지켜야 할 것

1. **수익 보장 표현 금지.** "월 ○○만원" 같은 문구는 법적 리스크(표시광고)이자 환불 사유다. 준비된 문구에는 이미 없음 — 임의로 추가하지 말 것.
2. **전자책 내용을 실제보다 부풀리지 말 것.** 16페이지 실행 가이드다. 그대로 팔아도 가격값을 한다.
3. **서비스는 받을 수 있는 만큼만 수주.** 납품 7일 약속 기준 주당 최대 3건.
4. **환불 요청은 빠르게 수용.** 분쟁 1건이 후기 10개를 망친다.

## 5. 72시간 후

- 목표 달성 여부와 무관하게: 전자책은 상시 판매 유지, 서비스는 후기 쌓이는 대로 가격 인상(49 → 59 → 79만원).
- 쇼츠 채널(원래 프로젝트)이 성장하면 그 자체가 이 상품들의 최고의 광고가 된다 — "이 시스템으로 운영하는 실제 채널".
- 다음 상품: 대본 월간 구독(주 5편 납품형) — 서비스 고객이 자연스럽게 전환되는 반복 매출.
