## STEP 1. 토스 송금 링크 2개 (3분)

1. 토스 앱 → 전체 탭 → 검색창에 "토스아이디" → **내 토스아이디**
2. 아이디가 없으면 생성 (예: `shortsfactory` — 채널명과 무관해도 됨)
3. 금액 지정 링크 만들기: **12,900원** → 링크 복사 → 기록표에 붙여넣기
4. 같은 방식으로 **19,900원** 링크 생성 → 기록
   - 형식: `toss.me/아이디/12900`, `toss.me/아이디/19900`

## STEP 2. 문의용 오픈채팅방 (3분)

1. 카카오톡 → 채팅 탭 → 우상단 + → 오픈채팅 → **오픈채팅방 만들기**
2. 유형: 그룹 채팅 / 이름: "쇼츠 공장 문의방" / 검색 허용 ON
3. 방장 프로필: 닉네임 프로필 사용 (실명 노출 방지)
4. 방 정보 → **링크 복사** → 기록표에 기록

## STEP 3. 구글폼 2개 (15분)

`sales/operations_kit.md`를 열어놓고 진행.

### 3-A. 주문서
1. forms.google.com → 새 양식
2. 제목·설명·질문 5개: **operations_kit.md 1-A를 그대로 복붙**
   - 질문 3(구성 선택)과 4(입금 여부)는 객관식, "필수" 토글 ON
   - 설명의 `[토스 링크]` 자리에 STEP 1의 링크 2개 붙여넣기
3. 설정 탭 → 응답 → **새 응답 이메일 알림 받기 ON** (발송 속도가 신뢰다)
4. 보내기 → 링크 아이콘 → URL 단축 → 기록표에 기록

### 3-B. 미리보기 신청 (리드 수집)
1. 새 양식 → **operations_kit.md 1-B 복붙** (질문 2개뿐)
2. 응답 알림 ON → 링크 기록
3. ⚠️ 미리보기 PDF는 이제 이 폼으로만 배포 (직접 파일 뿌리지 않기 —
   신청 메일이 오면 미리보기 PDF를 답장으로 발송)

## STEP 4. 상세페이지 배포 (2분) — ✅ 이미 라이브

상세페이지는 **https://wongnd.github.io/WonD/** 에 배포되어 있다 (2026-07-20, gh-pages).
Netlify 불필요. 남은 일은 하나:

1. STEP 1~3에서 만든 URL 5개를 기록표에 적은 뒤, Claude에게 그대로 전달:
   > "LINKS 채워서 재배포해줘: pay_basic=..., pay_pack=..., form=..., preview=..., contact=..."
2. Claude가 같은 URL로 재배포 → 브라우저에서 버튼 클릭 테스트
3. 상세페이지 URL을 스레드/X 프로필과 오픈채팅방 공지에 등록
   (LINKS가 비어 있는 동안 버튼은 "판매 준비 중" 안내가 떠서 안전함)

## STEP 5. 크몽 판매자 등록 + 상품 심사 신청 (30분) ⚠️ 오늘 필수

심사가 1~3일 걸리므로 다른 무엇보다 오늘 신청이 중요.

1. kmong.com → 회원가입 → **전문가 등록** (본인인증 필요)
2. 상품 등록 → 카테고리: 전자책 (또는 "투잡·노하우" 계열)
3. 제목·소개·목차·구매 안내: **`sales/ebook_listing.md` 그대로 복붙**
4. 가격 설정:
   - 기본: 12,900원 (전자책 PDF)
   - 옵션 추가 상품으로 "실행팩" +7,000원 등록 (파일: 실행팩.zip)
5. 파일 업로드: 전자책 PDF (구매 확정 시 자동 발송 설정)
6. 심사 제출 → 통과 알림 오면 Claude에게: "kmong_ebook에 [상품 URL] 넣고 재배포해줘"
   (직거래 UI가 자동으로 크몽 안전결제 버튼으로 바뀜)
7. ✚ 전문가 등록한 김에 **외주 서비스 3종도 같이 등록** — 원고:
   로컬 PC `Desktop/Wonyong company/launch-72h/kmong-gig-1~3.md` (복붙용 완성본)

## STEP 6. 베타 리더 + 지인 발송 (25분)
