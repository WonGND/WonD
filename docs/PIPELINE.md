# 제작 파이프라인 — 잡학 랭킹 (45초 쇼츠)

**목표: 1편당 60분, 주 5편.** 아래 순서를 그대로 따른다.

```
① 대본 (Claude)
   ↓
② Vrew — TTS + 자동자막
   ↓
③ 이미지 — Pexels / Pixabay / MS Designer
   ↓
④ BGM — YouTube 오디오 라이브러리 (볼륨 10~15%)
   ↓
⑤ MP4 내보내기
   ↓
⑥ 쇼츠 + 릴스 크로스 업로드
```

## ① 대본 (약 10분/편)
- `prompts/script_gen.md`의 프롬프트로 Claude에서 생성.
- **팩트 검증 메모의 [검증 필요] 항목을 반드시 확인** 후 확정.
- `scripts_content/weekXX/epNN.md`로 저장 후 커밋.

## ② Vrew — TTS + 자동자막 (약 20분/편)
- 새 프로젝트: **9:16, 1080x1920**.
- 대본 붙여넣기 → AI 목소리 선택(채널 전체 동일 목소리 유지) → 자동 자막 생성.
- 자막 스타일(한 번 설정 후 템플릿 저장):
  - 위치: **하단**
  - 색: **흰색**, **굵은 고딕**
  - 외곽선: **검정**
- 자막 오탈자/줄바꿈 수동 검수.

## ③ 이미지 (약 15분/편)
- 대본의 "이미지 키워드" 5개로 검색: Pexels → Pixabay → 부족하면 MS Designer 생성.
- 세로형(portrait) 우선. `tools/fetch_stock.py`로 일괄 다운로드 가능.
- **타인 영상 재사용 절대 금지.** 스톡 라이선스(상업적 사용 가능) 확인.

## ④ BGM (약 5분/편)
- YouTube 오디오 라이브러리에서 저작권 무료 트랙 선택.
- **볼륨 10~15%** — TTS 음성이 항상 또렷하게 들려야 함.
- 분위기: 미스터리/긴장감 계열 통일 (채널 톤 유지).

## ⑤ MP4 내보내기 (약 5분/편)
- 1080x1920, 원본 화질로 내보내기 → `output/weekXX/epNN.mp4` (git 제외).

## ⑥ 업로드 (약 5분/편)
- `templates/upload_checklist.md` 7항목 점검 후 업로드.
- YouTube 쇼츠 + Instagram 릴스 크로스 업로드.
- 업로드 시간: **18~21시**.
