# 마음에 관한 소름 돋는 심리 사실 TOP 5

## 후킹(첫 3초)
당신의 뇌가 당신을 속이는 방법, 소름 돋습니다.

## 본문
5위. 정작 뇌 자신은 통증을 못 느낍니다.

그래서 깨어 있는 채로 뇌 수술도 해요.

4위. 사람은 한 번에 대여섯 개만 기억합니다.

그래서 전화번호를 끊어서 외우죠.

3위. 눈을 굴릴 때마다 시야는 잠깐 끊깁니다.

뇌가 그 빈틈을 메워줘요.

2위. 익숙한 단어도 계속 보면 낯설어져요.

'의미 포화'라는 현상이죠.

1위. 기억은 떠올릴 때마다 조금씩 바뀝니다.

또렷한 기억일수록 왜곡됐을 수 있어요.

## 마무리
팔로우하면 내일 더 소름 돋는 사실을 알려드립니다.

## 이미지 키워드
human brain, memory abstract, eyes close up, repeated word text, old photograph memory

## 팩트 검증 메모
- 뇌 자체에 통각 수용체 없음 → 각성 상태 뇌수술(awake craniotomy) 가능: 사실.
- 단기기억 용량: 밀러의 "7±2" 고전. 최신 연구는 "약 4개" 주장도 있음 → "대략 대여섯 개"로 중간 표현. [검증 필요: 수치 단정 회피 유지]
- 사카드 억제(saccadic masking) — 안구 운동 중 시각 처리 억제: 사실.
- 의미 포화(semantic satiation): 사실, 심리학 용어.
- 기억 재응고화(reconsolidation)로 회상 시 변형: 사실(연구로 뒷받침). "또렷할수록 왜곡"은 섬광기억 연구 근거 → "있어요"로 완화.
